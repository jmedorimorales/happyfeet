# Happy Feet · Material de la clínica

App instalable (PWA) para controlar el material de la clínica de podología Happy Feet.
Abre la app de Google Apps Script (Sheet «HAPPY FEET - MATERIAL CLINICA») dentro de una carcasa con icono propio.

- Android (Chrome): abrir https://jmedorimorales.github.io/happyfeet/ › ⋮ › «Instalar app».
- iPhone (Safari): Compartir › «Añadir a pantalla de inicio».
- Si cambia la URL de Apps Script, cambiar `const EXEC` en index.html.
